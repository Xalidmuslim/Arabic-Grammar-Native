# Migration provenance
This native Android application is restored from the source archive and patches
of `Xalidmuslim/AlFatiha-Native`, branch `arabic-grammar-color-motion-rebuild`,
pinned at git commit `d99928a821ff980daebdd92bff7fbe2969002e2c`.

Original workflow `.github/workflows/build-arabic-grammar-color-motion.yml`
verified the original archive SHA-256, content database and all UI patch contracts.
This project's exact source and the post-patch database were imported after
the successful debug/release Gradle build and APK validation.
The old repo and its modules remain unchanged. Signing keys are not imported.
