# Арабская грамматика — Native Android

Отдельное Android-приложение. Исходная рабочая версия сохраняется в репозитории `Xalidmuslim/AlFatiha-Native`, ветка `arabic-grammar-color-motion-rebuild` (коммит `d99928a821ff980daebdd92bff7fbe2969002e2c`).

Исходники, база книги, интерфейс и накопленные исправления будут перенесены посредством проверяемой одноразовой сборки, **без переписывания программы**. Пока импорт не завершён, исходные файлы остаются доступны в первоначальном репозитории.

`Компаса сердца` и его встроенные модули это не затрагивает.
